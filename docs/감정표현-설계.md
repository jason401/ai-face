# 감정 표현 설계 — 78종, 11개 분류 (FACE3 엔진, FACE8 펌웨어)

## 조사와 선정 기준

- **Ekman 기본 감정**: 즐거움·슬픔·분노·두려움·놀람·혐오·경멸. 경멸은 한쪽 입꼬리만 올라가는 비대칭 표정으로 알려져 있어, FACE3에 입 비대칭(`tilt`)을 추가했습니다. https://www.paulekman.com/universal-emotions/
- **Cowen & Keltner (2017, PNAS)**: 자기보고 기반 27개 감정 범주(감탄, 경외, 어색함, 지루함, 차분함, 혼란, 갈망, 실망, 질투, 흥분, 공포, 죄책감, 흥미, 향수, 자부심, 안도, 만족, 공감, 승리감 등). https://doi.org/10.1073/pnas.1702247114
- **Cowen & Keltner (2020, American Psychologist)**: 얼굴·몸 표현으로 구분되는 28개 범주(집중, 혼란, 깨달음, 당황, 고통, 승리감, 안도 등). https://pmc.ncbi.nlm.nih.gov/articles/PMC6917997/
- **Geneva Emotion Wheel**: 긍정 10(흥미·즐거움·자부심·기쁨·쾌감·만족·감탄·사랑·안도·연민)과 부정 10(슬픔·죄책감·후회·수치·실망·두려움·혐오·경멸·증오·분노). https://www.unige.ch/cisa/gew
- **Plutchik 감정 바퀴**: 8개 기본 감정과 조합 감정(사랑, 낙관=기대, 경외, 경멸 등).
- **Kalegina 외 (HRI 2018)**: 화면형 로봇 얼굴 157개를 분석해 눈썹·볼(홍조)·색상 같은 요소가 인상에 영향을 준다고 보고했습니다. 그래서 눈썹, 홍조, 얼굴 색을 엔진에 추가했습니다. https://dl.acm.org/doi/10.1145/3171221.3171286

위 분류에서 작은 원형 LCD로 구분이 가능한 것을 고르고, 대화형 캐릭터에 필요한 **상태**(듣는 중, 말하는 중, 처리 중, 잠, 기상)와 **몸 상태**(아픔, 추움, 더움, 배고픔, 어지러움, 기절)를 더해 63종으로 정했습니다. 이 숫자는 제품 설계 판단이며, 얼굴만으로 실제 감정을 판별할 수 있다는 의미는 아닙니다. 모든 표정은 사람 표정의 정확한 재현이 아니라 만화형 캐릭터 표현입니다.

## FACE3 엔진 요소

| 필드 | 범위 | 의미 |
|---|---|---|
| move, hold | 80~5000, 0~10000 ms | 전환 시간, 유지 시간 |
| left, right | 0~100 | 눈 열림 % |
| x, y | −15~15, −10~10 | 시선 |
| width, smile, open | 10~100, −28~28, 0~30 | 입 폭, 곡률, 벌림 |
| brow | −10~10 | 눈썹 기울기 (+ 걱정 / − 화남) |
| lift | 0~12 | 눈썹 높이 (0 = 숨김) |
| eyes | 0~9 | 기본, ^^ 웃는 눈, ∪ 편안한 눈, X, 하트, 소용돌이, 별, 점, 초롱초롱, > < |
| tilt | −10~10 | 입 비대칭 (+ 오른쪽 입꼬리 올림) |
| fx | 비트 조합 | 1 홍조, 2 눈물, 4 땀, 8 Zzz, 16 하트, 32 화남 표시, 64 ?, 128 !, 256 반짝임, 512 음표 |
| color | 0~7 | 흰색, 분홍, 파랑, 노랑, 빨강, 초록, 보라, 주황 |
| shake | 0~6 | 떨림 |

연속 값은 부드럽게 보간되고, 눈 모양과 효과는 전환 중간 지점에서 바뀌며, 색은 RGB로 섞입니다.

## 분류 기준 (2026-10)

- **작업 중(Working)**: AI가 지금 하고 있는 일(생각, 집중, 듣기, 말하기, 처리, 읽기, "알겠어요").
- **태도·의견(Stance)**: 무언가에 대한 생각이나 입장(결의, 진지함, 의심, 끄덕끄덕, 도리도리).
- **실수·민망(Oops)**: 실수를 인정하거나 모른다고 말하는 순간(미안함, 당황, 민망함, 오글거림, 아차, 모르겠어요).
- 반가움·응원·배웅은 상대에게 건네는 표현이라 사랑·유대로 옮겼습니다.
- "자동"은 대기 화면(시계, 모닥불, 졸림→잠)이 그 역할을 해서 뺐습니다.

헷갈리기 쉬운 짝: 생각 중(답을 고민) / 처리 중(도구나 장치가 실제로 일하는 중), 기대(들뜸) / 조마조마(잘되길 빎), 혼란(이해가 안 됨) / 모르겠어요(판단할 근거가 부족), 미안함(상대에게) / 아차(내 실수를 깨달음). 처리 중·읽는 중처럼 작업만 나타내는 표정은 AI가 3분 넘게 그대로 두면 앱이 차분함으로 돌려놓습니다.

# AI Face 사용 방법

AI와 대화하면 AI가 고른 표정이 맥 메뉴바 오른쪽 위의 **동그란 얼굴**에 나타나요. ESP32 원형 LCD를 꽂으면 같은 얼굴이 실물 화면에도 나와요(선택).

## 처음 설치

1. **`앱 빌드.command`** 더블클릭
   - `AI Face.app`이 만들어지고 실행돼요. 메뉴바에 얼굴이 뜨고 설정 창이 열려요.
   - Xcode 명령줄 도구가 없으면 설치 창이 뜨니 설치하고 다시 실행하세요.
   - 예전 ESP32 Controller 앱이 켜져 있으면 자동으로 끄고, 로그인 시 자동 실행도 새 앱으로 바꿔요.
2. 설정 창의 **AI 연결** 탭에서 **Claude 데스크톱**과 **Codex** 옆의 **연결**을 눌러요.
   - 이 버튼 대신 `MCP 설치.command`를 실행해도 같아요.
3. Claude 데스크톱(과 Codex)을 **⌘Q로 완전히 종료한 뒤 다시 실행**해요.

`AI Face.app`은 이 프로젝트 폴더 안에 있어야 해요(폴더 안의 `core` 코드를 실행해요). 설정과 사진 보관함은 `~/Library/Application Support/ESP32Face`에 있어서, 폴더를 옮기거나 다시 빌드해도 그대로예요.

## 메뉴 (메뉴바 얼굴 클릭)

- **맨 위**: 큰 얼굴, 지금 표정 이름, 누가 골랐는지, 남은 타이머 또는 보드 연결 상태
- **타이머 ▸**: 5분 · 25분 · 50분 · 직접 입력… (돌고 있으면 **타이머 취소**가 생겨요)
- **모닥불 피우기**, **시계 보기**: 다음 표정이 올 때까지 유지돼요
- **표정 ▸**: 감정 분류별로 63가지 표정을 직접 고를 수 있어요(테두리 흰색)
- **설정…** (⌘,), **AI Face 종료** (⌘Q)

테두리 색은 누가 표정을 골랐는지예요: **주황** Claude, **초록** GPT, **흰색** 직접. 타이머가 돌면 테두리가 타이머 링이 돼요.

## 설정 창

### 일반
- **로그인할 때 자동 실행**: 맥을 켜면 메뉴바에 얼굴이 조용히 떠요.
- 설정과 사진 보관함 폴더를 Finder에서 열 수 있어요.

### 대기 화면
표정이 한동안 안 바뀌면 대기 화면으로 바뀌어요. 바꾸면 바로 저장돼요.

| 종류 | 화면 |
|---|---|
| 졸린 얼굴 → 잠든 얼굴 (기본) | N분 뒤 졸린 얼굴, 2N분 뒤 잠든 얼굴 |
| 시계 | 아날로그 시계 |
| 사진 | 보드에 지금 선택된 사진 |
| 사진 슬라이드쇼 | 보드에 저장된 사진을 10초~15분 간격으로 |
| 픽셀 모닥불 | 밤하늘 아래 타오르는 픽셀 모닥불 |
| 사용 안 함 | 마지막 표정 그대로 |

- AI가 새 표정을 보내거나 타이머가 끝나면 얼굴로 돌아와요.
- 사진·슬라이드쇼에서는 사진 위에 시계 바늘을 켤 수 있어요.
- 메뉴바에서는 시계와 모닥불은 그대로, 사진 종류는 잠든 얼굴로 보여요.
- 설정은 보드에도 저장돼서 맥이 꺼져 있어도 보드가 알아서 바꿔요.

### 사진
- **사진 보관함**: 사진을 끌어다 놓거나 **사진 추가…**로 넣어요. 크기와 형식(JPG, PNG, 아이폰 HEIC)은 상관없어요. 원본은 보관함 폴더에 모이고, 같은 사진은 중복으로 쌓이지 않아요.
- 보관함 사진을 **누르면** 240×240 원형 화면에 맞춰 줄여서 보드에 띄워요.
- **보드에 저장된 사진**(최대 10장): 누르면 다시 띄우고, 오른쪽 클릭으로 지워요.
- AI가 표정을 바꾸면 얼굴로 돌아가요. 사진을 오래 보려면 대기 화면을 사진이나 슬라이드쇼로 하세요. Claude에게 "사진 띄워줘"라고 해도 돼요.

### AI 연결
- **Claude 데스크톱**, **Codex (GPT)**: 연결 / 해제 버튼. 바꾼 뒤에는 그 앱을 ⌘Q로 껐다 켜야 반영돼요.
- **Claude Code**: **등록 명령 복사**를 눌러 터미널에 붙여 넣으세요.
- 다른 앱(로컬 stdio MCP 지원)은 표시된 **서버 명령**으로 등록하고, 환경변수 `ESP32_AGENT=claude` 또는 `gpt`로 테두리 색을 정해요.
- AI Face 앱이 켜질 때마다 등록된 MCP 서버 코드를 최신으로 맞춰서, 코드를 고친 뒤 다시 설치할 필요가 없어요.

AI가 쓸 수 있는 도구: `set_expression`(표정), `start_timer` / `cancel_timer`, `show_clock`, `show_photo`, `update_firmware`.

### 보드
- ESP32를 꽂으면 몇 초 안에 **자동으로 연결**돼요. 연결 상태와 마지막 메시지가 보여요.
- **펌웨어 업데이트**: `firmware/ESP32_Display`를 컴파일해서 보드에 올려요(Arduino IDE 창을 열 필요 없음). Arduino IDE 2가 응용 프로그램 폴더에 있어야 해요. 처음에는 1~2분 걸리고, 실패하면 컴파일 에러가 아래에 나와요.
- Claude에게 "펌웨어 올려줘"라고 해도 돼요(`update_firmware`).
- Arduino IDE로 직접 올리고 싶으면 AI Face를 종료한 뒤 올리세요(앱이 USB 포트를 쓰고 있어요).

## 보드 메모

- 보드: Seeed XIAO ESP32S3 + GC9A01 240×240 원형 LCD, 펌웨어 프로토콜 FACE7.
- Arduino IDE의 **Tools → Partition Scheme**은 이름에 spiffs가 들어간 기본값이어야 사진을 저장할 수 있어요.
- 다른 보드 설정이 필요하면 환경변수 `ESP32_FQBN`으로 바꿀 수 있어요.
- 앱을 꺼도 보드에 전원만 있으면 마지막 표정이 계속 움직여요.
- 타이머 남은 시간은 맥에도 저장돼서, 보드가 재시작돼도 이어져요.

표정별 움직임과 연구 근거는 `docs/감정표현-설계.md`, 전체 표정 모습은 `docs/표정-미리보기.png`에 있어요.

# AI Face 사용 방법

## 처음 설치 (새 맥 또는 새 폴더)

1. **`앱 빌드.command`** 더블클릭 → `AI Face.app`이 만들어지고 실행됩니다. 메뉴바 오른쪽 위에 동그란 얼굴이 뜹니다. (처음 한 번 Xcode 명령줄 도구 설치 창이 뜨면 설치하세요.) 예전 ESP32 Controller 앱이 켜져 있으면 자동으로 끄고, 로그인 시 자동 실행도 새 앱으로 바뀝니다.
2. **`MCP 설치.command`** 더블클릭 → Claude 데스크톱(과 Codex)에 `esp32-face`가 등록됩니다. 이미 등록되어 있었다면 그대로 새 코드로 바뀝니다.
3. Claude 데스크톱을 **Cmd+Q로 완전히 종료한 뒤 다시 실행**합니다. Codex도 다시 시작하세요.
4. (선택) ESP32 보드를 USB로 연결하면 같은 얼굴이 동그란 LCD에도 나옵니다.

설정과 사진 보관함은 `~/Library/Application Support/ESP32Face`에 있어서, 폴더를 옮기거나 앱을 다시 빌드해도 유지됩니다. 예전 `Documents/ESP32/사진 보관함`의 사진은 처음 실행할 때 한 번 자동으로 복사됩니다.

## ESP32 감정 모드

1. 기존 앱 화면의 **앱 종료**를 누르고 AI Face.app을 다시 실행합니다.
2. USB가 하나면 자동으로 연결됩니다. 연결되지 않으면 포트를 선택하고 **다시 연결**을 누릅니다.
3. **63가지 감정·상태 및 자동 모드** 중 하나를 누릅니다.
4. 선택한 감정의 동작을 자동으로 전송·저장하고 반복 재생합니다. 따로 설정하거나 저장 버튼을 누를 필요가 없습니다.

**자동**은 차분함, 호기심, 행복, 장난, 사랑, 졸림을 순서대로 반복합니다. 검색창에 "눈물", "땀" 같은 단어를 입력해 찾을 수도 있습니다. 화면 속 얼굴은 동작 미리보기로 실제 LCD와 재생 시점이 정확하게 같지는 않습니다.

**FACE7 엔진(타이머 링 + 사진 여러 장 + 대기 화면)으로 업데이트했으므로 `firmware/ESP32_Display/ESP32_Display.ino`를 한 번 다시 업로드해야 합니다.** 업로드 전에 앱의 **연결 설정 → 연결 해제**를 누르세요. 이전 버전 보드에 연결하면 앱이 업로드하라고 안내합니다. 이번 업데이트는 보드에 저장된 표정 데이터를 그대로 유지합니다. 대기용 졸림·잠 표정은 맥과 연결될 때 자동으로 보드에 들어갑니다.

앱을 종료해도 별도 전원이 공급되면 보드에서 계속 재생됩니다. 전원을 다시 켜면 마지막 감정 모드가 처음부터 재생됩니다.

시계를 원하면 **시계로 바꾸기**를 누릅니다. 보드 전원을 끊으면 시각은 초기화되므로 다시 동기화하세요.

펌웨어 업로드 시에는 **연결 설정 → 연결 해제 / 아두이노 업로드 준비**를 누릅니다. Safari 창만 닫으면 프로그램은 백그라운드에 남습니다. 완전히 종료하려면 **앱 종료**를 누르세요.

맥에 저장한 사용자 모드 데이터는 유지됩니다. 감정 버튼을 누르면 그 감정에 해당하는 보드 저장 위치가 기본 감정 데이터로 교체됩니다.

감정 분류 버튼으로 목록을 좁힐 수 있습니다. 표정별 움직임과 연구 근거는 `docs/감정표현-설계.md`에 정리했습니다. 추가 감정은 보드의 8번째 저장 위치를 공유하며 선택할 때 자동으로 교체됩니다. 9번째 저장 위치는 대기용 **잠** 표정 전용입니다. 전체 표정 모습은 `docs/표정-미리보기.png`에 있습니다.

## AI와 대화하면 표정이 바뀌게 하기 (MCP)

1. 폴더의 **`MCP 설치.command`**를 더블클릭합니다. Claude 데스크톱 설정에 `esp32-face`가 등록되고, 기존 설정은 자동으로 백업됩니다. macOS가 Documents 폴더를 보호하기 때문에, 서버 파일은 `~/Library/Application Support/ESP32Face`로 복사해서 실행합니다. 그래서 `core/aiface/` 코드를 수정했다면 설치를 다시 실행해야 반영됩니다.
2. Claude 데스크톱을 **Cmd+Q로 완전히 종료**한 뒤 다시 실행합니다.
3. ESP32를 USB로 연결한 채 대화하면, Claude가 답할 때마다 상황에 맞는 표정을 골라 화면에 띄웁니다. 처음 도구를 쓸 때 허용 여부를 묻는 창이 뜨면 **항상 허용**을 선택하세요.

- 컨트롤러 앱은 켜 두어도 되고 꺼 두어도 됩니다. 켜져 있으면 앱을 통해 보내고 미리보기도 따라 바뀝니다. 꺼져 있으면 MCP 서버가 USB를 잠깐 열어 보내고 바로 닫습니다.
- 다른 맥에서도 이 폴더를 복사한 뒤 `MCP 설치.command`를 실행하면 같은 방식으로 쓸 수 있습니다.
- Claude Code나 다른 앱에서도 쓸 수 있습니다. 로컬(stdio) MCP를 지원하는 앱이어야 합니다. 등록에 필요한 명령은 설치 창에 표시됩니다.
- **제거:** `MCP 제거.command`를 더블클릭하면 `esp32-face` 등록과 복사된 서버 파일이 지워집니다. 다른 설정은 그대로이고, 지우기 전 설정도 백업됩니다. 그다음 Claude를 재시작하세요. 완전히 정리하려면 AI Face 폴더를 지우면 됩니다(설정과 사진 보관함은 `~/Library/Application Support/ESP32Face`에 남습니다).
- 아두이노 업로드 중에는 USB를 쓸 수 없으므로 표정 전송이 실패합니다. 업로드가 끝나면 다시 정상 동작합니다.

## 누가 표정을 바꿨는지 테두리 색으로 구분 (FACE4)

- **흰색**: 컨트롤러 앱에서 직접 고른 표정
- **주황 `#D97757`**: Claude가 고른 표정 (Anthropic 브랜드 오렌지)
- **초록 `#10A37F`**: GPT(Codex 등)가 고른 표정 (ChatGPT 그린)

다른 쪽이 표정을 바꾸면 테두리가 한 번에 바뀌지 않아요. 12시 방향에서 시계 방향으로 약 1.2초 동안 새 색이 차오르고, 경계는 두 색이 부드럽게 섞입니다. 마지막 테두리 색은 보드에 저장되어 전원을 다시 켜도 유지됩니다. 시계 화면에서는 테두리를 그리지 않습니다.

**적용 순서 (한 번만)**
1. 컨트롤러 앱에서 **연결 설정 → 연결 해제**를 누르고 `firmware/ESP32_Display/ESP32_Display.ino`를 업로드합니다. 이전(FACE3) 보드에는 앱이 업로드하라고 안내합니다.
2. **`MCP 설치.command`**를 다시 실행합니다. Claude 데스크톱 등록에 `ESP32_AGENT=claude`가 추가됩니다.
3. Claude 데스크톱을 Cmd+Q로 종료 후 재실행하고, 컨트롤러 앱도 **앱 종료** 후 다시 실행합니다.
4. Codex(GPT)는 설치 창에 표시되는 명령(`codex mcp add esp32-face --env ESP32_AGENT=gpt -- …`)으로 다시 등록하면 확실합니다. 환경변수가 없어도 서버가 앱 이름(clientInfo)을 보고 Claude가 아니면 GPT로 판단합니다.

## 대기 화면 (FACE7)

표정이 한동안 바뀌지 않으면 보드가 알아서 **대기 화면**으로 바꿉니다. 앱의 **💤 대기 화면** 칸에서 시간과 종류를 고르고 **저장**을 누르세요.

| 종류 | 화면 |
|---|---|
| 졸린 얼굴 → 잠든 얼굴 (기본) | N분 뒤 졸린 얼굴, 2N분 뒤 잠든 얼굴 |
| 시계 | 아날로그 시계 |
| 사진 | 지금 선택된 사진 (사진 칸에서 테두리가 있는 사진) |
| 사진 슬라이드쇼 | 저장된 사진을 10초~15분 간격으로 돌아가며 |
| 픽셀 모닥불 | 밤하늘 아래 통나무 모닥불이 타오르고 불똥이 튀는 픽셀 아트 애니메이션 (보드가 직접 그려서 매번 조금씩 다르게 타요) |
| 사용 안 함 | 마지막 표정 그대로 |

- 앱의 **🔥 모닥불 피우기** 버튼으로 대기 시간 없이 바로 모닥불을 띄울 수도 있습니다(시계 버튼처럼, 다음 표정이 올 때까지 유지). 타이머는 모닥불 바깥 테두리에 표시됩니다.
- 사진·슬라이드쇼에서는 **사진 위에 시계 바늘 표시**를 켤 수 있습니다(시·분침, 1분마다 갱신).
- AI가 새 표정을 보내거나 타이머가 끝나면 원래 얼굴로 돌아오고, 시간을 처음부터 다시 셉니다.
- 사진이 없거나, 맥과 한 번도 연결되지 않아 보드가 시간을 모르면 졸린 얼굴로 대신합니다.
- **시계로 바꾸기**나 사진을 직접 띄운 경우에는 대기 화면이 동작하지 않습니다(다음 표정이 올 때까지 그대로).
- 대기 화면은 보드 안에서 돌아가므로 앱이나 Claude가 꺼져 있어도 동작하고, 설정은 보드에 저장됩니다.
- 이전의 "졸림/잠/시계 각각 몇 분" 설정은 대기 화면으로 바뀌었습니다(졸림 시간이 대기 시간으로 이어집니다).

### 타이머 링
- 앱의 **⏱ 타이머** 칸에서 5분, 25분, 50분이나 직접 입력한 시간으로 시작합니다. Claude에게 "25분 뽀모도로 타이머 켜줘", "다음 회의까지 타이머 맞춰줘"라고 말해도 됩니다(MCP 도구 `start_timer`, `cancel_timer`).
- 얼굴 화면에서는 주인 테두리(주황/초록/흰색) **바로 안쪽**에 링이 생기고, 12시 방향부터 시계 방향으로 줄어듭니다. 지나간 부분은 어둡게 남습니다.
- 시계 화면에서는 바깥 테두리 자리에 표시됩니다.
- 끝나면 링이 8초 동안 깜빡이고, 잠들어 있던 얼굴이 깨어납니다.
- 색: 파랑(기본), 빨강, 초록, 노랑, 주황, 보라, 분홍, 흰색.
- 남은 시간은 맥에도 저장됩니다. USB를 다시 연결해서 보드가 재시작되더라도 남은 시간부터 이어집니다.

### 적용 순서 (한 번만)
1. 앱에서 **연결 설정 → 연결 해제**를 누르고 `firmware/ESP32_Display/ESP32_Display.ino`를 업로드합니다.
2. **`MCP 설치.command`**를 다시 실행합니다(새 타이머 도구 반영).
3. Claude 데스크톱을 Cmd+Q로 종료한 뒤 다시 실행하고, 컨트롤러 앱도 **앱 종료** 후 다시 실행합니다. Codex는 다시 등록할 필요가 없고 재시작만 하면 됩니다.

## 사진 (FACE7)

- 앱의 **🖼 사진** 칸이나 앱 화면 아무 곳에 사진을 끌어다 놓으면(또는 칸을 눌러 선택하면) LCD에 바로 뜹니다.
- 크기는 상관없습니다. 앱이 240×240 원형 화면에 맞게 자동으로 줄입니다. JPG, PNG, 아이폰 HEIC 모두 됩니다.
  - **꽉 채우기**(기본): 화면을 가득 채우고, 넘치는 가장자리는 잘립니다.
  - **전체 보이기**: 사진 전체가 원 안에 들어가고, 남는 곳은 검은색입니다. 방금 올린 사진에서 바꾸면 그 사진이 다시 맞춰집니다.
- 보드에 **최대 10장** 저장되고 전원을 다시 켜도 남습니다. 칸 아래 동그란 사진을 누르면 그 사진을 띄우고, ✕로 지웁니다.
- AI가 표정을 바꾸면 얼굴로 돌아갑니다. 사진을 오래 보고 싶으면 대기 화면을 **사진**이나 **슬라이드쇼**로 설정하세요. Claude에게 "사진 띄워줘"라고 해도 됩니다(MCP 도구 `show_photo`).
- 타이머는 사진 위 바깥 테두리에 겹쳐서 표시됩니다.
- 화면이 16비트 색이라 그라데이션이 약간 거칠 수 있어서, 앱이 디더링으로 보정합니다.
- 이전 버전에서 올린 사진 한 장은 1번 사진으로 그대로 이어집니다.

### 사진 보관함
- 끌어다 놓은 사진의 **원본**이 `~/Library/Application Support/ESP32Face/사진 보관함` 폴더에 복사되어 모입니다. 개수 제한은 없습니다(보드에는 10장까지).
- 앱의 **📁 사진 보관함** 목록에서 사진을 누르면 보드로 보내 띄웁니다. ✕는 보관함에서 지웁니다(보드에 보낸 사진은 그대로).
- 같은 사진을 다시 올려도 중복으로 쌓이지 않습니다. 이름이 같은 다른 사진은 `이름 (2).jpg`처럼 저장됩니다.
- Finder에서 그 폴더에 사진을 직접 넣어도 몇 초 안에 목록에 나타납니다. **Finder에서 열기** 버튼으로 바로 열 수 있습니다.
- ESP32가 연결되지 않았을 때 끌어다 놓으면 보관함에만 저장됩니다. 여러 장을 한 번에 놓으면 모두 보관함에 들어가고 첫 장만 보드에 뜹니다.

### 적용 순서 (한 번만)
1. Arduino IDE의 **Tools → Partition Scheme**을 확인합니다. 이름에 **spiffs**가 들어간 기본값이면 그대로 두세요. "No FS"나 "Huge APP"처럼 저장공간이 없는 설정이면 사진을 저장할 수 없습니다. 앱에 "보드 저장공간(LittleFS)을 쓸 수 없습니다"라고 나오면 이 설정을 바꾸세요.
2. 앱에서 **연결 설정 → 연결 해제**를 누르고 `ESP32_Display.ino`를 업로드합니다. 추가 라이브러리는 필요 없습니다. 처음 켤 때 보드가 저장공간을 준비하느라 몇 초 늦게 켜질 수 있습니다.
3. **`MCP 설치.command`**를 다시 실행하고, Claude 데스크톱을 Cmd+Q로 껐다 켭니다. 컨트롤러 앱도 **앱 종료** 후 다시 실행합니다.

## Arduino IDE 없이 펌웨어 올리기

Arduino IDE 2 안에 들어 있는 arduino-cli로 `ESP32_Display.ino`를 컴파일하고 업로드합니다. IDE에 설치된 ESP32 보드 패키지와 라이브러리를 그대로 씁니다.

- **앱에서:** **연결 설정 → 펌웨어 업로드 (Arduino IDE 없이)**를 누르세요. USB 해제 → 컴파일 → 업로드 → 다시 연결까지 자동으로 합니다. 실패하면 컴파일 에러가 아래에 표시됩니다.
- **Claude에게:** "펌웨어 올려줘"라고 하면 Claude가 직접 올립니다(MCP 도구 `update_firmware`). 컴파일 에러가 나면 Claude가 에러를 보고 고칠 수 있습니다.
- 처음 컴파일은 1~2분, 그다음부터는 바뀐 부분만 다시 컴파일해서 빠릅니다.
- 보드 설정은 XIAO_ESP32S3 기본값입니다. 다른 설정이 필요하면 환경변수 `ESP32_FQBN`으로 바꿀 수 있습니다.
- 업로드하는 동안에는 Arduino IDE의 **Serial Monitor**를 닫아 두세요(USB 포트를 같이 쓸 수 없습니다).
- macOS가 Claude나 AI Face의 **Documents 폴더 접근**을 물으면 허용하세요.
- 파이썬 파일(앱, MCP)을 바꾼 경우에는 지금처럼 `MCP 설치.command` 실행과 앱·Claude 재시작이 필요합니다. 펌웨어(.ino)만 바꾼 경우에는 재시작이 필요 없습니다.

## 메뉴바 얼굴 (보드 없이도)

AI Face.app이 macOS 메뉴바(오른쪽 위)에 **동그란 얼굴**을 띄웁니다. 보드가 연결되어 있지 않아도 AI가 고른 표정이 여기에 나옵니다.

- 테두리 색은 실제 LCD와 같습니다: 주황 = Claude, 초록 = GPT, 흰색 = 앱. 타이머가 돌면 테두리가 타이머 링으로 바뀝니다.
- 대기 화면도 따라갑니다. 기본은 졸린 얼굴 → 잠든 얼굴입니다. 대기 화면이 시계면 메뉴바도 시계가 되고, 사진·슬라이드쇼·모닥불은 메뉴바에서는 잠든 얼굴로 보입니다.
- 얼굴을 누르면 메뉴가 나옵니다: 지금 표정·주인·보드 연결 여부, **컨트롤러 열기**, **로그인할 때 자동 실행**, **종료**.
- **로그인할 때 자동 실행**을 켜면 맥을 켤 때 브라우저 창 없이 메뉴바에만 조용히 뜹니다.
- 보드를 나중에 꽂으면 다음 표정부터 보드에도 자동으로 보냅니다.

### 처음 한 번
1. **`앱 빌드.command`**를 더블클릭합니다(맥 기본 개발 도구 Xcode Command Line Tools 필요, 없으면 설치 창이 뜹니다). 실행 중인 앱을 끄고, 새로 빌드하고, 다시 켜 줍니다. 빌드가 실패하면 내용이 `app-build.log`에 저장됩니다.
2. **`MCP 설치.command`**를 다시 실행하고 Claude(와 Codex)를 재시작합니다. 보드가 없어도 표정 변경이 실패하지 않게 바뀌었습니다.
